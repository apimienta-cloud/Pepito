# Diagnóstico Pepito — Agosto 2026 (Wasabi)

Diagnóstico web de lanzamiento para la marca Pepito (accesorios para mascotas):
benchmark de competencia (Salvajes.uy, Increíbles, Pet Care), contenido, pautados y recomendaciones.

## Contenido
- `index.html` — la página del diagnóstico (autocontenida: fuente e imágenes embebidas).
- `Diagnostico-Pepito-media/` — los videos que se reproducen dentro de la página.
- `.nojekyll` — evita el procesamiento Jekyll de GitHub Pages.

## Publicar (GitHub Pages)
Settings → Pages → Deploy from a branch → main / (root). Queda en
https://<usuario>.github.io/Pepito/  (mantené la carpeta de media junto al index.html).
